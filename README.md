# What's Today?
### Welcome to "What's Today" app repository. 
"What's Today" recommends various activities based on data from the American Time Use Surey (ATUS) and Meetup.com.
You can explore not only a wide range of activities but also interesting visualizations showing how people actually spend their free time.

Here is a link for the app: https://ql0713-somin-park.shinyapps.io/app_2/
We hope you can discover your new hobbies with this app!
